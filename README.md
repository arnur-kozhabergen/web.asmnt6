A small jQuery website with selectors effects DOM changes and animations
The mini project is a study break accordion menu

Website
https://arnur-kozhabergen.github.io/web.asmnt6/

Open index.html in a browser or use the website link
Internet is needed because jQuery 3.7.1 loads from a CDN
No installation or build step is needed
The navigation links open the five parts

Basics covers tasks 0 and 1
Open F12 and Console to see jQuery is ready!
Click Change examples to see ID class and tag selectors change text HTML and CSS

Effects covers tasks 2 to 4
Try Hide Show and Toggle on the paragraph
Use the Fade buttons on the photo
Use the Slide buttons on the panel

DOM covers tasks 5 to 7
Add Item adds at the end and Add at start adds at the beginning
Remove Item removes the last list item
Change image changes the local image file
Change link opens a different destination when the link is clicked
Type a name and email to see them below the form
The form does not send or store information

Animations covers tasks 8 to 10
Animate square changes size and position
Run sequence moves right then down then shrinks and returns
Combine changes animates size movement and opacity together
Click a button again to restart its example

Mini project covers task 11
Click Before class During practice or Snack break
One section opens at a time
Click the open section again to close it
The buttons also work with the keyboard
